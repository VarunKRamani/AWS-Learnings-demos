# Cost Management and Billing.

AWS Cost Management and Billing are the tools and services provided by AWS to track, analyze, allocate, and optimize your cloud expenditure.

**Cost Anomaly Detection**: Automatically catches unusual or unexpected spending spikes using machine learning.

**Setting of Budget**:
AWS Budgets allows us to track and control our cloud spending before costs get out of hand. Instead of reviewing expenses at the end of the month, we can set proactive spending and usage limits.

- **Automated Threshold Alerts**: Set alerts to trigger when actual or forecasted spend reaches a specified percentage (e.g., 80% or 100%) of our budget limit. Receive immediate alerts via Email, Amazon SNS, or Slack/Teams integrations when thresholds are breached.

- Cost Management Preferences allow us to configure how AWS handles our account statements, cost reports, and invoicing notifications.

- Granular Data settings control the level of detail and frequency at which AWS records and displays our cost and usage metrics in Cost Explorer.

- Resource-level data at daily granularity is a specific setting within AWS Cost Explorer that lets you break down our cloud spending by individual resource IDs (such as specific EC2 instances, S3 buckets, or RDS databases) on a daily basis.
